# Thématiques de la semaine

Un fichier par semaine, nommé d'après le **lundi** de la semaine : `AAAA-MM-JJ.md` (ex. `2026-11-09.md`).
Écrit par AQ Croissance (Hermès) ou par Rénald ; lu chaque jeudi à 17 h 47 (heure de Montréal) par la routine Claude qui produit les visuels.

Statuts, dans l'ordre : **Proposée** → **Visuels en cours** → **Visuels prêts** (mis par la routine) → **Publiée** (mis par Hermès).

## Modèle

```markdown
# Semaine du 2026-11-09

## Région — Fiche région : Laurentides
Catégorie : Région
Territoire : Québec
Angle : …
Pistes de contenu : …
Statut : Proposée

## Valeur ajoutée — …
Catégorie : Valeur ajoutée
Territoire : …
Angle : …
Pistes de contenu : …
Statut : Proposée

## Cabinet — …
Catégorie : Cabinet
Territoire : …
Angle : …
Pistes de contenu : …
Statut : Proposée
```

La routine ajoute ensuite sous chaque thématique une ligne `Dossier visuels : visuels/semaines/AAAA-MM-JJ/<dossier>`.
