# Calendrier éditorial

## Lancement d'un compte (méthode validée)
Semaine 1 : 7 posts + 7 stories organiques ; stories rangées en bulles (Offre, Équipe, Retours clients).
Semaine 2 : publicité payante sur le contenu qui a le mieux fonctionné.
Épingler le post de présentation. Publier ≥ 3 posts avant d'inviter ses contacts.

## Trame hebdomadaire type (régime de croisière)
| Rythme | Contenu |
|---|---|
| 2 posts/sem. | **Problématique client** (voir problematiques.md) |
| 1 post/sem. | Méthode / conseil pratique (Structurer · Financer · Démontrer) |
| 1 post/2 sem. | Preuve : retour client, mandat réalisé (avec accord) |
| 1 post/2 sem. | Équipe, coulisses, présence terrain (tournées, rencontres d'organismes) |
| Ponctuel | Offre organismes ; événements |
Stories : 3 à 5 par semaine, relais des posts + questions/sondages sur les problématiques (elles alimentent les prochains posts).

## Promouvoir un événement (webinaire, atelier, conférence)
1. J-30 à J-21 : teaser (« Quelque chose commence — Rendez-vous le [date] »), Reel motion design.
2. Page d'inscription (Eventbrite ou autre) + outil de diffusion (ex. Zoom Webinar) ; fuseau réglé sur l'heure de l'Est.
3. Événement Facebook + couverture 1920 × 1005 ; bannière de billetterie 2:1.
4. J-21 à J-7 : publicité (objectif inscriptions), stories avec mot-clé en message privé → lien d'inscription.
5. J-2 et jour J : rappels ; ensuite, post de remerciement et replay/ressource.
Une fois l'événement passé : retirer les mentions temporaires (bio, intro FB, bulle, réponses automatiques).
